# Core Profile — Shared User Profile Options

## Purpose

The `core.profile` module declares a set of shared user-profile options that act as a single source of truth for values
consumed by other modules — desktop environments, shell companions, and display managers — rather than hardcoded literals.

## Entry Point

- **Profile options**: [`modules/home-manager/core/profile.nix`](../../../../modules/home-manager/core/profile.nix) — avatar, wallpaper and location.
- **Identity options**: [`modules/home-manager/core/profile/identity.nix`](../../../../modules/home-manager/core/profile/identity.nix) — the user's public key.
- **Supporting file**: [`modules/home-manager/core/default.nix`](../../../../modules/home-manager/core/default.nix) — imports both modules automatically

## Architecture / Services / Scope

The module only declares options; it does nothing on its own.
Consumers use `config.core.profile.*` to read the values.

### Options

{{#include ../../../generated/core-profile-options.md}}

#### `core.profile.avatar.path`

Path to the user avatar image.
Used by the Noctalia desktop shell (via `programs.noctalia.settings.shell.avatar_path`) to display the user picture in the bar and session UI.

#### `core.profile.wallpaper.directory`

Directory containing wallpaper images.

**Consumers:**

| Consumer                    | How it uses the value                                             |
| --------------------------- | ----------------------------------------------------------------- |
| Noctalia desktop shell      | Sets `programs.noctalia.settings.wallpaper.directory`             |
| GNOME azwallpaper extension | Sets `org/gnome/shell/extensions/azwallpaper slideshow-directory` |

#### `core.profile.location.secret`

Name of a SOPS secret whose decrypted value becomes the Noctalia `location.address`.
When unset, the location block is omitted from the Noctalia config entirely.
At activation time, the decrypted secret is appended to a base Noctalia config TOML (generated by the module)
and written to `~/.config/noctalia/config.toml` — the clear-text address never lands in the repo or Nix store.

#### `core.profile.identity.publicKey`

Path to the user's OpenSSH public key file.
The default is `home/{username}/id_ed25519.pub` in the flake, and an assertion fails evaluation when that file does not exist.
The module links the file to `~/.ssh/id_ed25519.pub`, so consumers can read a user's key from one declared path instead of hard-coding one.

**Consumers:**

| Consumer                  | How it uses the value                                                                                       |
| ------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `purpose.development.vcs` | Default for `purpose.development.vcs.user.publicKey`; supplies the signing key and the allowed-signers entry |

## Secrets

- `core.profile.location.secret` — name of a SOPS secret (not a literal value) whose decrypted content supplies
  the Noctalia location address at activation time.

### Usage Example

```nix
{ ... }: {
  core.profile = {
    avatar.path = "/home/user/.face";
    wallpaper.directory = "/home/user/Pictures/Backgrounds";
    location.secret = "noctalia-location";
    identity.publicKey = "/home/user/.ssh/id_ed25519.pub";
  };
}
```

## Operational Notes / Assumptions

- The GNOME azwallpaper extension consumes `core.profile.wallpaper.directory` via `dconf-extensions.nix` (`home/shared/desktop/gnome/`).
